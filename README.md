# まちの足カルテ（開発中）

> **開発中です。** 画面・データの形・判定の決まりは、これから変わります。知らせの内容は、必ず事業者の時刻表でも確かめてください。

## 目的

住んでいる人がよく使うバスの移動（乗るバス停・降りるバス停・曜日・時刻の希望）を登録しておくと、バスの時刻表が変わるときに、**その人の移動に影響があるときだけ**知らせるアプリです。公共交通オープンデータチャレンジ2026 に出すために作っています。

- 登録した内容は、端末の中（ブラウザの localStorage）だけに保存し、外に送りません。アカウントもありません。
- 全国の GTFS データの新しい版を、GitHub Actions で6時間ごとに見に行き、便や時刻が変わった版から「改正のデータ」を作って、GitHub Pages から配ります。

## しくみ

| 場所 | 中身 |
|---|---|
| `scripts/01〜05` | 調査：新しい版が改正の何日前に出ているか（結果は `REPORT.md`） |
| `scripts/06_build_revision.py` | 2つの版から、アプリ用の「改正のデータ」を作る |
| `scripts/07_daily_watch.py` | 全国のフィードを見に行き、新しい版を記録し、改正のデータを作る |
| `scripts/calendar_rules.py` | 祝日・年末年始・お盆・一日だけの特別な日の決まり |
| `app/` | アプリ（静的なサイト）。判定は `app/js/judge.js` で、端末の中で動く |
| `site` ブランチ | 見に行った記録と、公開するデータ（Actions が更新する。main と履歴を分けている） |
| `docs/` | 設計・報告 |

## 出典

- GTFS データは、[GTFSデータリポジトリ](https://gtfs-data.jp/)（運営：一般社団法人 社会基盤情報流通推進協議会）で公開されているものを使っています。各フィードのライセンスは、フィードを提供している事業者・自治体が定めています。
- 改正のデータを作って公開するのは、加工と再配布が認められているライセンス（CC BY 4.0、CC0 1.0、CC BY 2.1 JP）のフィードだけです。公開しているフィードごとの出典は、`site` ブランチの `ATTRIBUTION.md` と `data/attributions.json` に自動で載せます。
- 版の一覧などのメタデータは、GTFSデータリポジトリの付帯データ（CC BY 4.0）です。
- 祝日は、内閣府「国民の祝日」CSV を使っています（`data/jp_holidays.csv`）。
- GTFS の zip ファイルそのものは、このリポジトリに入れていません。

## 手元で動かす

```
cd app && python3 -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/?today=2026-11-25&demo=1
cd app && npm test
```
